# 🪙 Crypto Tracker

Это простой fullstack-проект для отслеживания информации о криптовалютах.  
Состоит из бэкенда на FastAPI и фронтенда на React (Vite + Tailwind + Ant Design).

---

## ⚙️ Что делает

- Отображает список криптовалют
- Позволяет выбрать любую монету
- Показывает:
  - текущую цену
  - рыночную капитализацию
  - изменение цены за 24 часа и за 30 дней

---

## 🧱 Стек

- **Frontend**: React + Vite + TailwindCSS + Ant Design
- **Backend**: FastAPI (Python)

---

## 🧠 Зачем это

Проект создан как pet-project для практики:
- fullstack-разработки
- взаимодействия frontend ↔ backend
